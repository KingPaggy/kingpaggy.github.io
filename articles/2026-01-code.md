# 代码-1

<!-- 代码，代码运行，代码编辑 -->

代码描述的是给计算机下达的一组命令。
写代码是书写顺序执行命令的逻辑。
代码运行是这组命令在机器上的运行。
代码的运行有始有终，一般是从 `main` 开始运行，有不同的运行终点。

指令集合、代码集合称作程序。
程序是运行在机器上的。需要一个信号，程序才能开始运行。
这个信号，可以来自操作系统，也可以来自硬件的触发。

编辑代码就是修改指令集合中指令的内容。
为了描述运行的逻辑，代码的组织中需要声明很多变量。
重复的逻辑整理为函数，解决多处代码段重复的现象，增加可读性，同时也可以缩小源代码行数。
因声明了变量、函数，任何一段源代码都是有上下文的。
某一段代码调用了哪些函数，修改了哪些变量，这一段代码前文是什么场景，后续会执行什么逻辑。
在编辑代码的时候，需要在不同的源代码位置之间跳动。
跳动的基本逻辑有，前往函数的声明处，前往函数被引用的地方。

代码的**逻辑地图**大了，就需要多个文件了。
逻辑地图可以理解为，从一个点跳到源代码的任意另一个点需要不停的跳转，跳转的过程像是信息在走“图”（数学中的概念）的路径。
这时是把源代码看作是一张图，图中的节点是代码段（函数名），图中的连接可以看作是上下文关系，或者是函数的跳转。
一个未经证实的推断是，变量的作用域可以看作是点的集合。
